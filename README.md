## Descripción

Este proyecto contiene una base de datos SQL para un negocio, ejemplos de métodos HTTP utilizando JSONPlaceholder y una aplicación web que consulta Pokémon mediante la PokeAPI.

## Estructura

- `db/`: estructura, datos y consultas SQL.
- `pokeapi/`: archivos complementarios del proyecto PokeAPI.
- `frontend/`: aplicación web para buscar Pokémon.
- `docs/`: documentación y capturas de pantalla.
